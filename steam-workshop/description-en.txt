[h1]Real Snow Without Advanced Shaders[/h1]

With the [b]Advanced Shaders[/b] graphics option turned off, winter on the map is a flat, patchy paint job. This mod gives the low spec map the real snow: a solid cover with its own relief and sheen and a frost layer at the edges — while keeping the option off.

This is an add-on for [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3800159542]Sharp Terrain Without Advanced Shaders[/url]: it needs that mod above it in the load order, and it is one small options file - no shader is duplicated.

[h2]The cause[/h2]

With Advanced Shaders off the terrain pixel shader draws snow with ApplySnowDiffuse(): three taps of the snow texture at different scales overlaid into a mask, thresholded by the province's winter severity and painted over the ground colour. No height blend, no normals, no roughness, no frost. With the option on, the game runs ApplySnowMaterialTerrain() instead, which blends a proper snow material into the ground the way the ground materials blend into each other.

The expensive path never depended on anything the low spec shader lacks. It needs the per pixel detail height, normal and material — exactly what Sharp Terrain already computes and vanilla low spec throws away. Sharp Terrain carries the call behind an option, and this mod switches the option on.

[h2]What it costs[/h2]

About 4 ms of frame time where snow is possible, measured on a 4 GB laptop GPU at 5120x1440 in January; nothing in the south, where the snow mask lets the shader exit after one tap. On that machine the low spec 60 FPS held.

[h2]Notes[/h2]

[list]
[*][b]Keep Advanced Shaders off.[/b] With it on the game uses the high spec effect and this mod does nothing at all
[*]Only the terrain is touched. Trees keep the snow their own shader gives them
[*]Graphics-only: no gameplay, script or history files, so ironman and achievements are unaffected
[*]Safe to add or remove at any time, including mid-campaign
[*]The first map load after enabling is slower: the modified shader is compiled and cached from scratch
[*]Built for CK3 1.19.x. Shader overrides replace the vanilla file wholesale, so a patch that reworks pdxterrain.shader will need an update here
[/list]

[h2]Compatibility[/h2]

Contains a single file, gfx/FX/sharp_terrain_options.fxh, which overrides the options file of Sharp Terrain Without Advanced Shaders. Requires that mod, placed above this one. Conflicts with nothing else.
